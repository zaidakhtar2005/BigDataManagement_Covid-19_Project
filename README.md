# BigDataManagement_Covid-19_Project
COVID-19 Data Analysis using Apache Spark and MongoDB Atlas (BDM Project)

**Author:** Ajaz Ahmad  
**University:** University of Calabria – DIMES Department  
**Course:** Big Data Management (BDM)

## Description
This project analyzes the global COVID-19 dataset from Kaggle using Apache Spark (batch processing) and exports processed results to MongoDB Atlas (NoSQL storage).

## Technologies
- Apache Spark 3.4.1 (PySpark)
- Python 3.10
- MongoDB Atlas
- Java 11 (for Spark runtime)
- WSL Ubuntu 22.04

```bash
python3 project_queries.py
